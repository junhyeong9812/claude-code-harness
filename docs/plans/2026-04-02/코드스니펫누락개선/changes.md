## 0.1 문서 작성 절대 규칙

**이 규칙은 plan.md, context.md, checklist.md, learned.md 등 모든 산출물 작성 시 적용된다.**

### 코드 스니펫은 반드시 포함한다
- plan.md의 "참고 코드 스니펫" 섹션, learned.md의 "사용 예시" 섹션을 **비워두지 않는다.**
- 코드 블록(```)이 있는 섹션에는 **실제 코드**를 작성한다. 플레이스홀더(`(여기에 작성)`)로 남기지 않는다.
- 코드는 **메모리에서 재현하지 않는다.** 반드시 해당 파일을 Read 도구로 다시 열어서 복사한다.

### 문서 작성 전 파일 재읽기
- 문서(특히 learned.md)를 작성하기 **직전에**, 이번 작업에서 생성/수정한 모든 파일을 다시 열어서 읽는다.
- "아까 읽었으니 기억한다"고 하지 않는다. **다시 읽는다.**
- 읽은 코드에서 필요한 부분을 문서에 직접 옮긴다.

### 토큰 절약 금지
- 문서 작성에서 토큰을 아끼지 않는다.
- 코드가 길더라도 의미 있는 전체 단위(함수, 클래스, 설정 블록)를 포함한다.
- `... (생략)` 또는 `// 나머지 코드`로 축약하지 않는다.
