## 4. 도메인 지식

- 이 오케스트레이션 문서는 Claude Code의 행동을 제어하는 "소프트 프롬프트 규칙"이다.
- 하드 블록(훅, 설정)과 달리, 문서 규칙은 Claude가 "읽고 따르는" 형태이므로 **명확성과 구조**가 핵심이다.
- "선언적 규칙"(~하지 마라)보다 "절차적 규칙"(~하기 전에 반드시 ~해라)이 Claude에게 더 효과적이다.
- Claude는 "멈추는 시점"(부정적 정의)보다 "진행 조건"(긍정적 정의)을 더 잘 따른다.
