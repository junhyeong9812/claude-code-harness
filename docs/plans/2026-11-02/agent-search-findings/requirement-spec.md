## 2. 경계·불변식 (필수)

- **근거가 받치는 만큼만 규칙화한다.** 근거 = clean-code-llm-experiment 1~3차 결론(파일럿 n=1 사후 관찰). 지침 문구는 "권장·기본"이지 금지·강제가 아니고, 근거 링크와 "미측정" 범위를 함께 적는다.
  - 받침: 에이전트는 코드에 그대로 있는 낱말(파일 이름·식별자·문자열 키·API 낱말)로 고칠 곳에 닿는다(20실행 일관) · 찾기 턴은 1~3턴으로 작다(3차). *(재합의 — 삭제: "통째 읽기는 읽은 양·비용을 늘렸다" — 3차 결론 §3.3이 원인 미분리를 명시)*
  - 받치지 않음(규칙화 금지): "통째 읽기가 비용을 늘린다" · "파일명이 명확하면 토큰이 준다" · "파일을 잘게 나누면 나쁘다/좋다" · "탐색을 싼 모델에 맡기면 토큰이 준다" — 후자는 ADR-0009 측정 뒤.
- **워커 기본 모델(Opus·high) 변경 금지** — 측정 전.
- 상시 문서 비용: core 증가 ≤ +3줄(현 134, 상한 150) · playbook ≤80줄 유지.
- core §2 "변경 대상과 호출처는 전체를 읽는다"와 충돌하지 않게 — 범위 읽기는 위치 찾기 단계에만.
- 훅·상태·settings 무변경.
- 기존 measurement-log 행(타 프로젝트 포함) read-only.
