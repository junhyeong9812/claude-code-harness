# 최종 검증 요청: changelog.md 산출물 도입 결과물

너는 독립 교차 검증자(다른 모델)다. 방금 적용된 최종 상태다. 검증: ① 이전 8지적이 실제 반영됐나 ② 문서 간 충돌·단일 출처 위반 ③ 집행 공백(트리거·커버리지·작성 시점이 실행 가능하게 닫혔나). 단서: 발췌 밖(learned 템플릿·phase 템플릿 등)에 정의가 이미 존재할 수 있다 — 발췌에 없다고 미정의로 단정하지 말 것. 신뢰도 높은 지적만, 심각도+수정안. 한국어로.

## 신설: templates/changelog.md (전문)
```
# changelog: {작업명}

> 목적: **사용자의 코드 리뷰 능력 훈련** — 각 구현의 근거를 추적 가능하게 남긴다. learned.md와 경계: 이 문서 = **이번 diff의 의사결정 로그**(스니펫은 여기에만) / learned.md = 전이 가능한 새 지식(여기 항목 ID를 참조, 필요 시 대표 스니펫 1개만 재인용).

> 인용 규칙: 코드 블록은 실파일에서 그대로 복사 — **블록 안에 해설 주석을 삽입하지 않는다** (실파일 복사 규칙 위반). 해설은 라인별 근거 표로.

**검증 상태**: 통과 / 일부 실패 / 실행 불가 — (검증 명령 · 실패 로그 요약 · 실행 불가 사유)

## 커버리지 규칙 (전수 분류 — 자의적 축소·팽창 방지)

최종 diff(`git diff --name-only`)의 **모든 변경 파일이 J/M/G 중 하나로 등장**해야 한다 — 작성 후 셀프체크 □.

- **J(판단)**: 동작·API/CLI 계약·데이터/schema/query·에러 처리·트랜잭션·검증/정규화·보안/권한·동시성/cache/시간/env·알고리즘/자료구조·성능/자원·테스트 전략에 영향 → §1 풀 항목. public API rename도 J.
- **M(기계)**: 동작 동일한 import 정리·포맷·순수 rename·순수 이동 → §2 1줄 + **동작 동일 근거**.
- **G(생성)**: lockfile·generated·snapshot → §3 1줄 + 원인 J 항목 참조.
- 불확실하면 J로 (최소 1줄 근거).
  ```

```
### 3.5 기록
- `docs/measurement-log.md`에 1행 (<1분: 유형·stakes·총 소요·하네스 오버헤드·재작업·테스트 실패 후 수정·검증이 잡은 결함·오탐·생략 게이트·머지 후 결함은 발견 시 추가 기입). 이 데이터가 §0-3(규칙 증감은 측정 근거)의 입력이다.
- **learned.md — 사용자의 학습용 제품 산출물 (프로세스 기록 아님).** 트리거는 stakes가 아니라 **학습 가치**: 새 라이브러리·패턴 / 비직관 버그 / 테스트 전략 변경이 나온 작업은 **풀 작성**(`templates/learned.md` 10항목, 코드 스니펫 포함), 그 외엔 task.md 안 5줄 요약. 사용자가 요청하면 언제든 풀로.
- **changelog.md — 사용자의 리뷰 훈련용 제품 산출물 (learned와 별개).** 코드 구현이 있는 작업마다(코드·스크립트·스키마 — 문서-only 제외, stakes 무관) 작업 폴더에 작성 — **검증 단계 종료 후·최종 응답 전**. 형식·커버리지 규칙(J/M/G 전수 분류)·근거 출처 필드는 `templates/changelog.md` 단일 출처. learned와 경계: changelog = 이번 diff의 의사결정 로그(스니펫은 여기에만) / learned = 전이 가능한 지식(changelog 항목 ID 참조).

**문서 인용 규칙 (모든 산출물 공통)**: 코드 블록은 **실파일에서 복사**한다 — 메모리 재현 금지, placeholder·`...(생략)` 금지, 작성 직전 해당 파일 재읽기. 컨텍스트가 요약된 뒤의 기억은 신뢰하지 않는다.

산출물은 기본 **`task.md` 1파일** (정의+계획+검증+기록 통합). 위치: 대상 프로젝트 `docs/plans/YYYY-MM-DD/작업명/`.

**경량 경로 폐지 (2026-06-10 사용자 결정)**: 모든 정의됨 작업은 task.md를 작성한다. 전 차원 비활성이 자명한 작업(오타·주석 수준)의 트리아지 1행 축약만 허용 — 형식은 dimensions.md 사용법을 따른다.
```
