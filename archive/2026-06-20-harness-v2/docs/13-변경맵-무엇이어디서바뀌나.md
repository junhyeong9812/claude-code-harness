## 4. 의존 관계 (왜 묶어야 하나)

```
A(검증 트리거 축소) 는 단독 적용 금지
   └─ 반드시 G(승격) + H(최소안전선) 와 함께   ← 없으면 "누락 허용"(codex 경고)
E(측정) 는 A보다 먼저/동시      ← 없으면 A 효과를 "느낌"으로만 판단
F(졸업) 는 A의 연료            ← catch→체크리스트 졸업이 있어야 하네스가 실제로 줄어듦
```

## 6. 정직 노트 — 이 맵이 오늘 작업을 되돌린다

오늘 세션에서 추가한 **B2.5 독립 게이트(impl)·페이즈 6파일 배선**이 본 맵에서 🔻격하 대상이다. 같은 날 만든 걸 같은 날 격하하는 셈 — 이건 실수가 아니라 **하네스 재귀 위험(좋은 아이디어가 게이트로 굳음)의 실증**이고, 그래서 E(측정)·F(졸업)가 핵심이다. definition.md·domain-contracts.md 템플릿과 페이즈 산출물 개념 자체는 유지된다.
