# playbook: fast-mode (모드 fast)

> 트리거: 구현 모드 = **fast** (task-mode-guard·gate-guard 훅 — core §1 구현 모드 5종 표). auto/lazy/pair/refactor와 독립한 완결 프로토콜.
> 목적: "정의하고 있을 시간이 없는" 케이스 — 스모크(실행 확인)만 즉시, 정의·계획·리뷰·테스트·문서는 **빚으로 후불**한다. 긴급(장애 대응)의 정식 경로다(core §3.1).
> 단일 출처: `docs/plans/2026-07-19/harness-v3-restructure/` (D5, 사용자 확정 2026-07-19).

## 0. 이 모드가 아닌 것

- **검증 생략이 아니다**: 검증·codex·테스트·리뷰는 사라지지 않고 **뒤로 미뤄질** 뿐이다 — 빚은 반드시 갚는다(§3). "빨리 = 대충"이 아니다.
- **불변은 그대로 산다**: 외부 발행 승인(core §6.5)·불가역 명령 개별 승인(core §6.4)·최소 안전선의 실행 확인(core §4.3 ①)은 fast여도 **면제되지 않는다**(§4).

## 1. 진입 턱 (게이트 대신 — 1회 확인)

- fast는 정의 게이트(6칸)의 유일 예외다(core §1·§3.2) — 정의·계획은 후불 빚, **진입 확인이 게이트·승인을 대신한다.**
- 진입 시 **딱 1회** 확인한다: 이 작업이 **불가역 데이터 작업**(마이그레이션·기존 데이터 변경·대량 삭제·원본 덮어쓰기)을 포함하나?
  - 포함하면 그 조작은 fast여도 §6.4대로 **개별 사용자 확인**을 받는다(진입 턱과 별개 — 턱은 승인이 아니라 인지 확인).
  - 이 턱은 "빠르게 가되 되돌릴 수 없는 문은 열지 말라"는 안전 한 겹이다.

## 2. 스모크 즉시 (최소선 ①만 앞당김)

- 변경 경로를 **실제로 실행**해 눈으로 동작을 확인한다(렌더·호출·잡 실행) — core §4.3 ①. 이것만 즉시, ②~⑥(테스트·self-review·contract·반증질문)은 빚으로 넘어간다.
- 스모크는 "에러 없이 돌았다"의 최소 증거다 — silent failure(부분실패 DONE 위장·무음 스킵)를 스모크로 능동 반증한다(core §6.3).

## 3. 빚 (task-process `## fast 빚` = 정본)

- 후불하는 항목(정의·계획·듀얼 리뷰·테스트·문서·안전선 ②~⑥)을 발생 즉시 task-process의 **`## fast 빚`** 섹션에 적는다 — 이 섹션이 빚의 **정본**이다.
- **FAST_DEBT 상태 토글 (모델 책임 — 훅은 자동 토글하지 않음)**:
  - fast **진입 시** 세션 상태파일의 `FAST_DEBT=1`을 켠다(빚 미상환 표식).
  - 빚 **전건 해소 시** `FAST_DEBT=0`으로 끈다.
  - `FAST_DEBT`는 미러 플래그다 — 정본은 `## fast 빚`. 상태파일 경로는 reinject-mode가 매 턴 재주입하고, 쓰기는 core C3 상태 계약(temp+mv 원자 교체·flock)을 따른다. reinject-mode가 매 턴 빚 1줄을 재주입해 컨텍스트 요약 후에도 상기시킨다.
- **완료 선언 금지**: 빚이 남은 동안 "작업 완료"를 선언하지 않는다 — 스모크 통과는 착수 증거이지 완료가 아니다.
- **차기 L1 우선**: FAST_DEBT=1인 채로 다음 정의됨(L1) 작업에 진입하려 하면, 새 작업보다 **미상환 빚 해소를 먼저** 처리한다.

## 4. 불변 (fast여도 면제 없음)

- 외부 발행(push·이슈·MR/PR·원격 브랜치 생성)은 각각 **사용자 확인 후**(core §6.5) — 빠르다고 추측 발행하지 않는다.
- 불가역 명령(`--force`·`reset --hard`·DB 변경 실행·마이그레이션·대량 삭제)은 **개별 승인 후**(core §6.4). 파괴적 조작 직전 브랜치·HEAD·경로·대상 재확인.
- 검증 강도 자체는 stakes 비례(core §5) — fast는 강도를 **낮추는** 게 아니라 **미루는** 것뿐이다.

## 5. 종료

- 종료 = **빚 전건 해소** + `FAST_DEBT=0`. 미룬 정의·계획·리뷰·테스트·문서·안전선 ②~⑥을 모두 소급 기입·수행한 뒤에야 태스크가 끝난다.
- 소급 기입 0회 전례가 D5의 근거다 — "나중에"가 "안 함"이 되지 않도록 종료 조건으로 강제한다.
