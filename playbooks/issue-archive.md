## 1. 추출 — log.md에서 CS 이슈만

- 이번 작업 log.md 타임라인에서 **실제로 발생한 문제 + 원인 + 해결**을 고른다.
- **CS 이슈** = 프로젝트 밖 사람에게 같은 문장으로 설명되는 기술 원리(언어·런타임·프레임워크·빌드·OS·동시성·네트워크·DB·인프라·보안·신뢰성·테스트 신뢰성·셸). 하네스·훅의 기술 결함도 포함.
- **제외**: 도메인·비즈니스 규칙, 문서 표기, 리뷰·게이트 절차 자체.
- 0건이면 log.md에 `아카이브: CS 이슈 0건` 1행으로 끝낸다(무음 생략 금지).
- study-note 경로가 없거나(타 머신) 작업 불가하면 log에 `아카이브 보류: <사유>` 1행 + 사용자 보고 — 조용히 건너뛰지 않는다.
- **보안 결함은 출처 무관 패치·배포 완료 후에만** 아카이브한다(공개 repo — 미패치 취약점 공개 금지, 하네스 훅 우회 포함).

## 2. 매칭 — 기존 카드와 같은 원리인가

`cs/issue/README.md` 인덱스로 후보를 찾고 카드 본문을 읽어 판정한다. 판별 질문: *"두 이슈를 밖의 사람에게 설명할 때 같은 문장으로 시작하나?"*

```
이슈 ──▶ 같은 원리 카드 있나?
          ├─ 없음 ─────────────▶ ⓐ 새 카드(authoring-guide 형식, 필요하면 새 분류 폴더)
          └─ 있음 ─▶ 해결 방안이 같나?
                     ├─ 같음 ──▶ ⓑ 변경 없음 (log에 "기존 카드 <경로> 동일 — 무변경" 1행)
                     └─ 다름 ──▶ ⓒ 3-answer.md 끝에 `## 방안 비교` append
```

- **append-only**: 기존 서술은 고치지 않는다. ⓒ는 새 섹션만 덧붙인다 — 방안 A(기존)·B(이번)의 추상화 코드, 비교 표(전제·비용·실패모드·적용 조건), **결론: 어느 쪽이 언제 더 나은가**(조건부 결론 허용, 근거 없는 우열 금지).
- 오류 정정이 필요하면 본문 수정 대신 `## 정정` 섹션 append.

## 3. 공개 안전선 (형식·서술은 authoring-guide가 정본 — 여기는 공개 노출 경계만. guide에 같은 규칙이 있으면 guide 문언을 따르고, guide가 이보다 느슨하면 이 절이 하한)

- **출처를 적지 않는다** — 프로젝트명·회사명·파일 경로·라인·클래스명·내부 호스트·시크릿·실코드 대신, 문제 코드와 연결 코드를 **추상화한 코드**로 구조를 보인다.
- 검증 근거(원 파일·라인)와 원 식별자는 **작업 log.md에만** — 카드에는 넣지 않는다.
- 날조 금지 — log·코드에서 확인한 것만.

## 4. 커밋·push

- **브랜치**: 배치마다 `archive/<YYYY-MM-DD>` 브랜치에서 커밋 → push 확인 시 main에 fast-forward 병합 후 push(core §6 브랜치 우선). ff 불가·push 거절이면 브랜치를 남기고 log 1행 + 보고(다음 배치는 그 브랜치에 이어 커밋).
- **커밋 전 노출 스캔**: 스테이징한 카드 diff를 log에 기록한 원 식별자(프로젝트·회사·클래스·호스트명) + `review.md §5①` 시크릿 패턴 + 경로·IP 패턴으로 grep — 실식별자·시크릿·호스트·경로·IP는 **0건이어야 커밋**, 일반 명사 매칭은 review.md §5①처럼 오탐 개별 판정(근거 log 1행) 후 커밋.
- **카드(패턴 폴더) 1개 = 커밋 1개**. 그 카드 파일 + 영향받은 인덱스 README만 `git add <경로>`로 스테이징 — `git add -A`·`.` 금지(study-note의 무관한 미커밋 변경 혼입 방지). 커밋 전 `git diff --cached --stat`으로 범위 확인.
- 메시지: `docs(cs/issue): <카드명> — <신규|방안 비교|정정>`. 검증 과정 출처·AI attribution 금지(core §6).
- push는 배치 끝 1회, 사용자 확인(core §6) — 확인 요청에 카드 목록과 출처 유형(개인/회사/하네스)을 함께 제시.
- 원 작업 log.md에 `아카이브: <카드 경로> <ⓐ|ⓑ|ⓒ> <커밋 SHA>` 행 기록.
