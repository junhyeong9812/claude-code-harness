## 4. 참고 코드 스니펫

> **⚠️ 이 섹션은 생략하지 않는다.**
> 리서치 단계에서 읽은 기존 코드 중, 구현에 참고할 코드를 여기에 붙여넣는다.
> 최소 1개 이상의 코드 블록을 포함한다. 메모리에서 재현하지 않고 파일에서 직접 복사한다.
> 참고할 기존 코드가 없는 경우(신규 프로젝트 등), 스킬 문서에서 참고한 패턴 코드를 포함한다.

```
(파일에서 직접 복사한 코드)
```

**코드 분석:**

> 아래 항목을 빠짐없이 작성한다.

**사용된 메서드/함수:**
| 메서드/함수 | 소속 (라이브러리/클래스) | 역할 | 반환값 |
|------------|----------------------|------|--------|
| | | | |

**문법/언어 기능 설명:**
> 코드에서 사용된 언어 고유 문법을 설명한다.
> 예: 제네릭, 람다, 스트림, 패턴 매칭, 데코레이터, 컴프리헨션, 타입 힌트 등
> "이 문법이 왜 여기서 사용되었고, 어떻게 처리되는가"를 설명한다.

**동작 방식:**
> 이 코드가 실행될 때 내부적으로 어떻게 동작하는지 단계별로 설명한다.
> 재귀, 반복, 콜백, 비동기 처리 등의 흐름을 명시한다.
> "왜 이렇게 하면 이런 결과가 나오는가"를 설명한다.
